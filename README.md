# SpendIQ

### Spend smarter. Save better.

**SpendIQ** is a modern personal finance and budget management desktop application built with C++. It aims to help users track daily transactions, manage monthly budgets, monitor savings goals, and understand their spending habits through interactive financial analytics.

> Take control of your money, one transaction at a time.

## ✨ Planned Features

- **Expense Tracking** – Record, edit, delete, and categorize daily expenses.
- **Income Management** – Track income sources and financial activity.
- **Smart Budgeting** – Create monthly and category-wise spending limits.
- **Savings Goals** – Set financial targets and monitor progress.
- **Financial Analytics** – Visualize spending patterns and monthly trends.
- **Transaction History** – Search, filter, and organize transactions.
- **Financial Reports** – Generate summaries and export transaction data.

## 🛠️ Technology Stack

| Technology | Purpose |
